SVG – Scalable Vector Graphics

SVG is an XML-based format for vector graphics. It stays sharp at any size and can be styled/animated with CSS.

Sample – Basic circle with text
<svg width="120" height="120" viewBox="0 0 120 120">
  <circle cx="60" cy="60" r="50"
          fill="#38bdf8" stroke="#0f172a" stroke-width="4" />
  <text x="60" y="68" text-anchor="middle"
        fill="#0f172a" font-size="22" font-weight="bold">SVG</text>
</svg>
Sample – Multiple shapes

Advanced Selectors

Powerful selectors reduce extra classes and keep CSS maintainable.

Sample – Attribute, pseudo-class & combinators
/* Attribute selectors */
input[type="email"] { border-color: #38bdf8; }
a[target="_blank"]::after { content: " ↗"; }

/* Pseudo-classes */
a:hover,
a:focus-visible { color: #7dd3fc; }
li:nth-child(odd) { background: rgba(255,255,255,0.03); }
tr:nth-child(even) { background: #1e293b; }
input:invalid { border-color: #f87171; }
input:valid { border-color: #34d399; }
button:disabled { opacity: 0.5; cursor: not-allowed; }

/* Pseudo-elements */
p::first-line { font-weight: 600; }
.card::before {
  content: "";
  position: absolute;
  inset: 0;
  border-radius: inherit;
  padding: 1px;
  background: linear-gradient(135deg, #38bdf8, #818cf8);
  mask: linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0);
  mask-composite: exclude;
}

/* Combinators */
article > p { margin-bottom: 1rem; }   /* direct child */
h2 + p { margin-top: 0.5rem; }         /* adjacent sibling */
h2 ~ p { color: #94a3b8; }             /* general sibling */
Sample – Modern :is(), :where(), :has()
:is(h1, h2, h3, h4) {
  line-height: 1.2;
  color: #f1f5f9;
}

:where(ul, ol) {
  padding-left: 1.25rem;
}

/* Style parent based on child */
.card:has(img) {
  padding-top: 0;
}

label:has(+ input:invalid) {
  color: #f87171;
}

/* Form group that contains a required field */
.form-group:has([required]) label::after {
  content: " *";
  color: #f87171;
}

CSS Positioning

The position property changes how an element participates in the document flow.

Sample – All position values
/* Static – normal flow (default) */
.box-static {
  position: static;
}

/* Relative – stays in flow, can be offset */
.box-relative {
  position: relative;
  top: 20px;
  left: 30px;
}

/* Absolute – removed from flow, positioned against nearest positioned ancestor */
.box-absolute {
  position: absolute;
  top: 40px;
  right: 40px;
}

/* Fixed – relative to the viewport */
.box-fixed {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

/* Sticky – hybrid of relative + fixed */
.box-sticky {
  position: sticky;
  top: 0;
  background: #1e293b;
  z-index: 10;
}

/* Creating a containing block */
.parent {
  position: relative; /* now absolute children position against this */
}

Browser Compatibility

Check support and provide graceful fallbacks.

Sample – Feature queries & progressive enhancement
/* Feature queries */
@supports (display: grid) {
  .container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 1rem;
  }
}

@supports not (display: grid) {
  .container {
    display: flex;
    flex-wrap: wrap;
  }
  .container > * {
    flex: 1 1 300px;
  }
}

/* Progressive enhancement */
.button {
  background: #38bdf8;                    /* solid fallback */
  background: linear-gradient(135deg, #38bdf8, #818cf8);
}

/* Container queries (modern) */
@supports (container-type: inline-size) {
  .card-container {
    container-type: inline-size;
  }
  @container (min-width: 400px) {
    .card { flex-direction: row; }
  }
}
Sample – Checking support in JavaScript
if (CSS.supports("display", "grid")) {
  document.body.classList.add("supports-grid");
}

if (CSS.supports("selector(:has(*))")) {
  console.log(":has() is supported");
}

Introduction to CSS Grid

CSS Grid is a two-dimensional layout system — perfect when you need control over both rows and columns.

Sample – First Grid
.container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  gap: 1rem;
  min-height: 100vh;
}

/* Flexbox = 1D (row OR column)
   Grid     = 2D (rows AND columns) */

Use Flexbox for

  • Navigation bars
  • Card content alignment
  • Centering items
  • Simple one-directional layouts

Use Grid for

  • Page layouts
  • Dashboards
  • Image galleries
  • Complex 2D arrangements

Creating a Grid

Sample – Defining tracks
.grid {
  display: grid;

  /* Fixed + flexible columns */
  grid-template-columns: 200px 1fr 2fr;

  /* Equal columns */
  grid-template-columns: repeat(3, 1fr);

  /* Responsive auto-fit */
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

  /* Rows */
  grid-template-rows: 80px 1fr 60px;

  /* Gap */
  gap: 1rem;                  /* both row and column */
  row-gap: 1.5rem;
  column-gap: 1rem;
}

Advanced Grid Properties

Sample – Alignment & auto-placement
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;

  /* Align items inside their cells */
  justify-items: stretch;   /* start | end | center | stretch */
  align-items: stretch;

  /* Align the whole grid when extra space exists */
  justify-content: center;
  align-content: start;

  /* Auto-generated tracks */
  grid-auto-rows: minmax(100px, auto);
  grid-auto-flow: dense;    /* tries to fill holes */
}

/* Individual item alignment */
.item {
  justify-self: center;
  align-self: end;
}
Sample – Responsive card grid (no media queries)
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 1.5rem;
}

Using Flexbox and Grid Together

Best practice: Grid for page structure, Flexbox inside components.

Sample – Combined layout
/* Page shell with Grid */
.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 64px 1fr;
  grid-template-areas:
    "sidebar header"
    "sidebar main";
  min-height: 100vh;
}

.sidebar { grid-area: sidebar; }
.header  { grid-area: header; }
.main    { grid-area: main; }

/* Header content uses Flexbox */
.header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 0 1.5rem;
  gap: 1rem;
}

/* Card inside main also uses Flexbox */
.card {
  display: flex;
  flex-direction: column;
  gap: 0.75rem;
  padding: 1.25rem;
}
